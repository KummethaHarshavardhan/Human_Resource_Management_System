# Human Resource Management System (HRMS)

A production-level Human Resource Management System (HRMS) developed as a collaborative team project. The application is designed to streamline HR operations, including employee management, attendance tracking, leave management, payroll processing, and reporting through a modern web interface.

---

## Project Overview

The HRMS aims to provide a centralized platform for managing employees and HR-related activities. It follows a modular architecture where different teams develop independent modules that are integrated into a single application.

---

## Features

### Authentication & User Management
- User Registration & Login
- JWT Authentication
- Role-Based Access Control (Admin, HR, Employee)
- User Profile Management

### Employee Management
- Employee CRUD Operations
- Employee Profiles
- Department Management
- Role Assignment

### Attendance & Leave Management
- Employee Check-In / Check-Out
- Attendance Tracking
- Leave Application
- Leave Approval Workflow
- Leave History

### Payroll & Reports
- Salary Management
- Payroll Processing
- Payslip Generation
- Reports & Analytics

### UI/UX
- Responsive Dashboard
- Sidebar Navigation
- Modern User Interface
- Mobile Friendly Design
